**Waraq 1.0 beta 4 — PDF studio for Arabic and English. Your files never leave your device.**

Download **`Waraq_1.0.0-beta.4_x64-setup.exe`** below (Windows 10/11, 64-bit, about 29 MB). Installs for your user only, no administrator rights; beta 3 users get it as an automatic update. Not code-signed yet: if Windows shows "unknown publisher", choose **More info → Run anyway**. Or use Waraq in your browser: https://www.pwaraq.com/app/

New in beta 4:
- **New start screen:** open or drop files, then pick what you want to do — Sign, Portfolio, Scan to text, Combine, Fill a form, Share safely, Drawings or Review — and the file opens in the right tool.
- **Move area:** cut any part of a page — a piece of a picture, a block of a drawing — and move it; lines and text stay sharp.
- **Layers in Edit:** a list of every picture, moved area, text box and cover on the page. Pick one even when it is covered, bring it to the front or send it back, or hide it while you work.
- **Small files after editing:** editing one page of a file whose pages share fonts and pictures no longer makes the saved file huge (a 3.5 MB, 54-page file used to grow to 175 MB; now it stays 3.5 MB). Organize and Portfolio benefit too.
